# ZOVI – Your AI-Powered Study Companion

**ZOVI** is an AI-powered smart study assistant designed to make learning smarter, simpler, and more personalized. It aims to provide students with intelligent academic support through an interactive and user-friendly learning experience.

##  Features

- **AI Study Assistance** – Get intelligent academic support.
- **Interactive Interface** – A clean, student-friendly design.
- **User Authentication** – Account and session management using Supabase.
- **Membership Plans** – Free and Premium plan interface.
- **AI Integration** – Backend services for AI-powered functionality.
- **Responsive Design** – Designed for an accessible learning experience.

##  Tech Stack

##  Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

```bash
 https://github.com/Gurleen3178/ZOVI.git
```

2. Open the project folder:

```bash
cd ZOVI
```

3. Install dependencies:

```bash
npm install
```

4. Configure the required environment variables using a local `.env` file.

5. Start the backend using the start command configured in `package.json`.

6. Open the frontend through a local development server.

##  Security

- Sensitive credentials should be stored in environment variables.
- Never commit `.env` files or private API keys.
- Supabase access should be protected with appropriate Row Level Security (RLS) policies.

##  Membership

ZOVI includes a Free and Premium membership interface. Membership switching is currently a demonstration feature and does not itself process real payments.
